# Vibe Coding Parent Outreach

> Status: `active`  
> Purpose: 面向小学阶段孩子家长的小红书内容运营与咨询承接  
> Entrypoint: `content/POST_LIBRARY.md`  
> Validation: `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\validate.ps1`  
> GitHub: local-only，等待首轮内容验证后再决定是否建立远端  
> Next: 确认账号名称、授课方式与可公开联系方式，发布首批 3 篇帖子

这个项目把现有 Vibe Coding 家教简历与作品集转化为可持续运营的小红书内容系统。它不保存各作品源码，只维护公开传播所需的事实、文案、图片副本、家长沟通流程和交接记录。

## 阅读顺序

1. [PROJECT_FACTS.md](./PROJECT_FACTS.md)：唯一可直接用于公开文案的已核实事实与链接。

6. [operations/PUBLISHING_CHECKLIST.md](./operations/PUBLISHING_CHECKLIST.md)：每次发布前后的检查流程。
7. [HANDOFF.md](./HANDOFF.md)：继续运营时的最短交接路径与待确认事项。

## 项目边界

- 只面向家长进行公开沟通，不在公开评论区收集孩子的学校、班级、住址、照片等信息。
- 不承诺升学、竞赛获奖、编程等级或短期结果；只展示已经核实的经历和作品。
- 不自动发布帖子、不自动回复私信；发布、报价和正式约课由姚飞本人确认。
- 小说改编项目只作为非商业交互研究案例，不作为少儿商业课程素材直接复用。
