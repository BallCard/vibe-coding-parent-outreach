# 发布与复盘清单

## 发布前

- [ ] 本帖只回答一个家长问题。
- [ ] 所有数字与经历均可在 `PROJECT_FACTS.md` 找到。
- [ ] 通用名称写作 `Vibe Coding`，没有误写成其他概念。
- [ ] 没有虚构奖项、学员案例、家长评价、招生名额和课程效果。
- [ ] 标题没有制造 AI 落后焦虑，也没有承诺速成。
- [ ] 图片中没有孩子身份、学校、住址、私信或其他隐私。
- [ ] 若使用沉浸式小说图片，已明确非商业研究与原作版权边界。
- [ ] 行动引导只有一个：留言、私信关键词或查看作品集。
- [ ] 价格、授课方式、联系方式和二维码已经本人确认。

## 发布后 24—72 小时

- [ ] 记录发布日期、标题和帖子链接。
- [ ] 记录收藏、评论、私信等真实反馈，不只看点赞。
- [ ] 把高频家长问题追加到选题库。
- [ ] 私信按 `PARENT_COMMUNICATION.md` 先了解孩子情况。
- [ ] 不公开转发家长或孩子的信息。
- [ ] 判断下一篇应继续解释认知、拆解项目，还是发布招募信息。
